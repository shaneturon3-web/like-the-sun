## Current reading

The strongest shared mechanism is not “family” or “memory” in the abstract. It is **how a material arrangement determines whether a person can remain present without being trapped**.

The same payload appears under different vehicles:

- relationship boundary;
- domestic furniture;
- inherited object;
- child/sea arrival;
- door and latch;
- delayed or withheld speech.

## Non-collapse rule

Do not infer that every chair is the same story, or that every door is the same symbol. Preserve four fields independently: material object, local function, pressure, and corpus surface. Only the mechanism may be provisionally shared.

## Next resolution change

Compare one full scene from each surface around the transition:

`object appears → person interprets it → function is tested → memory changes status`.

## Newly found mechanism: object-to-function reversal

The three surfaces do not merely use objects as symbols. They begin with an interpretation and then force the object or image to prove what it can do:

- **Like the Sun**: “sun” begins as an image for continuing affection; the dialogue tests it as a boundary. The image survives only after access is removed. Memory changes from possible re-entry to safe distance.
- **Pre-like / chairs**: the chair begins as design and achievement; the children mark it. The mark tests whether the object is a museum piece or a family object. Memory changes from perfect preservation to lived belonging.
- **NINO**: the door and stone begin as incomplete traces; the small weight is tested in the door. The object does not explain the child; it performs a temporary function until the maintainer arrives.

The shared operation is therefore:

`initial reading → material/relational test → function outranks interpretation → memory is reclassified`

This is stronger than the earlier “object as memory carrier” hypothesis. The object is an adversarial witness: it refuses the first elegant meaning unless the function survives contact.

Still open: whether this operation is a governing rule of the three-book corpus or a recurrent family resemblance. More scenes are needed before promoting it to corpus law.
